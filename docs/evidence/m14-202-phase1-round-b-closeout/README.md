## 7. 协议差异 caveat（h2，防过度归因）

- 本地 curl 与 VPS 443 协商出 **HTTP/2**（curl `http_version` 报
  `ver=2`，被动记录，未强制）；Phase 0 公网观测恒 **HTTP/1.1**
  （M14-199 §10.4 预先落档的边界）。
- 因此本地-公网差值**含协议因素**：不得据此声称"h2 更快/更慢"的
  因果结论；h2 归因需 h2 强制参照组，该参照组**从未被授权**（不在
  默认计划与 reserve 授权内），本轮**未运行**。
- `ver=2` 仅作为"宿主 443 具备 h2 能力"的免费事实记录（M14-199
  §3.3 H5 上下文），不进入 H1 判定输入。
