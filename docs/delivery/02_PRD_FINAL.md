# AI Learning OS 2026 PRD v2

版本：v2.1  
目标用户：以中国高校/终身学习场景为主的多课程学习者  
产品形态：响应式 Web 优先，语音为一级入口，后续扩展移动端

## 1. 产品目标

帮助用户每天用最低决策成本完成学习、练习、考试和复盘。系统自动完成课程资源组织、题目选择、语音交互、判分、错因分析、复习排程和下一轮个性化推荐。

### 成功标准

1. 用户从打开系统到开始今日任务不超过 3 次点击。
2. 一套语音选择题可以从读题到总分报告连续完成。
3. 一套在线试卷在刷新、断线、超时和重复提交后状态一致。
4. 每个外部课程、题目和解析都有来源与授权状态。
5. 第二次学习计划能反映第一次错题、掌握度和遗忘风险。

## 2. 用户与场景

| 用户 | 场景 | 主要诉求 |
|---|---|---|
| 自学者 | 同时学习多门公开课 | 自动组织资料、生成每日任务、追踪掌握度。 |
| 备考者 | 限时刷真题和模拟卷 | 权威计时、自动判分、错题讲解、变式训练。 |
| 通勤学习者 | 无法持续看屏幕 | 语音读题、语音作答、语音复盘。 |
| 课程构建者 | 将资料转成课程 | 大纲可审、内容可改、测验可追踪。 |

## 3. 信息架构

首页一级入口：

1. 今日学习
2. 开始语音
3. 开始考试

次级入口：

- 课程库
- 题库与试卷
- 错题本
- 学习报告
- 资源发现
- 设置

首页展示当前课程、今日任务、待复习、最近错题和考试提醒，但不把模型配置、解析细节、来源审核等复杂度暴露给普通用户。

## 4. 功能需求

### F1 今日学习

**用户故事**：作为学习者，我希望打开系统就知道今天学什么、练什么、复习什么，不需要自己规划。

后台流程：

1. 读取学习目标、课程进度、考试日期。
2. 读取 Student Concept State 和误解候选。
3. 读取遗忘风险和复习队列。
4. 选择学习内容、练习题和复盘任务。
5. 生成时间盒任务。

验收：

- 每日计划由历史学习事件影响。
- 每个任务绑定课程、概念、目标和学习材料。
- 用户可跳过、延后或反馈太难，但系统记录原因。

### F2 语音做题

**用户故事**：我希望像听老师报题一样完成整套选择题，最后得到总分和错题讲解。

功能：

1. TTS 播报题干和选项。
2. 支持重复题目、重复选项、慢一点、跳过、修改答案、暂停、继续、结束。
3. 用户可说“选 B”、“第二个”、“我改成 C”、“不知道”。
4. ASR 输出先进入 intent parser，再进入 answer normalizer。
5. 客观题由确定性逻辑判分。
6. 全卷完成后播报总分、正确率、错题数量。
7. 错题讲解分四层：正确概念、用户答案为何错、干扰项排除、同类技巧。
8. 自动生成变式练习。

验收：

- 20 题连续语音作答不丢状态。
- 打断 TTS 后 500ms 内停止播报并进入倾听状态。
- “我改成 C”能覆盖之前的 B。
- 考试语音模式禁止泄露答案和搜索。
- 语音会话断线重连后从当前题恢复。

### F3 在线考试

**用户故事**：我希望像真实考试一样限时做题，提交后自动批阅并解释每个知识点。

功能：

1. 支持从题库选择、导入试卷或 AI 生成草稿卷。
2. 服务端创建考试并生成不可篡改的 `start_at`、`end_at`。
3. 答案自动保存，事件 append-only。
4. 支持标记题、跳题、题目导航、剩余时间提醒。
5. 到期自动提交，未答题按策略记零或标记未答。
6. 客观题、数值题、代码题和主观题走不同评分路由。
7. 报告包含总分、题型得分、概念得分、时间分布、错题和补救任务。

验收：

- 修改客户端时间不影响剩余时间。
- 重复提交只产生一个最终 submission。
- 刷新和断线重连后答案与剩余时间一致。
- 超时自动提交在服务器触发。
- 每个评分结果能追溯到题目、答案、规则或 judge 版本。

### F4 全网课程与真题发现

**用户故事**：我希望让系统找某大学某课程的公开讲义、作业、考试或真题，并自动变成可学习对象。

功能：

1. 解析学校、课程代码、年份、学科、语言和资料类型。
2. 生成官方站、图书馆、OER、GitHub、课程平台的搜索计划。
3. 结果去重、分级、排序。
4. 识别访问控制和授权状态；官方课程站、图书馆、OER 与社区仓库使用不同信任策略。
5. 对允许解析的内容执行 OCR/文档解析。
6. 生成 Course、Resource、Question、Concept、Evidence。
7. 对无法入库的内容保留入口、摘要和授权说明。

验收：

- 每个结果展示 source tier、URL、获取时间、license state。
- UNKNOWN license 不进入公共可复用池。
- ACCESS_CONTROLLED 内容不绕过登录或权限。
- 检索计划、排序依据和弃用原因可查看。

### F5 错题本与补救

功能：

1. 按课程、概念、错因、时间和频次组织错题。
2. 区分概念错误、先修缺失、计算错误、理解错误、审题错误、时间压力等。
3. 同一误解在多题重复出现时升级为长期画像。
4. 为每个错题生成修复题、同构题和迁移题。
5. 使用 FSRS-like 调度安排复习。

验收：

- 错题报告能指出错在哪个概念或步骤。
- 复习任务优先级来自掌握度、遗忘风险和考试日期。
- 单次错误不立即改写长期学生画像。

### F6 课程生成

功能：

1. 输入目标、材料、课程和考试日期。
2. 生成能力目标、先修图、概念 DAG、资源选择、课程大纲。
3. 用户确认大纲后生成章节、讲解、练习和测验。
4. 每个生成对象保留来源和人工确认状态。

验收：

 不是一句话直接生成最终课程；必须先输出可审核的学习目标和结构。

## 5. 非功能需求

| 类别 | 要求 |
|---|---|
| 可用性 | 核心流程响应式适配桌面和手机；语音界面可盲操作。 |
| 可靠性 | 考试答案至少本地缓存 + 服务端事件存储；提交幂等。 |
| 可追溯 | 模型调用、评分、检索和语音状态记录 trace。 |
| 可扩展 | 模型、ASR、TTS、搜索、OCR、存储全部 adapter 化。 |
| 隐私 | 支持本地推理、本地语音和私有文档模式；云端调用显式路由。 |
| 安全 | SSRF 防护、沙箱执行、密钥隔离、权限矩阵、prompt injection 防御。 |
| 观测 | 每条链路记录 latency、cost、quality、failure stage。 |

## 6. MVP 非目标

1. 不做万人并发在线教育平台。
2. 不做社交社区和直播课。
3. 不承诺全自动爬取所有大学受限真题。
4. 不在 MVP 中训练专属大模型。
5. 不做复杂图数据库优先架构。
6. 不让 LLM 决定考试剩余时间或客观题对错。
7. 不默认把公开网页内容合并进公共可再分发题库。

## 7. 发布分层

| 阶段 | 目标 | 范围 |
|---|---|---|
| P0 | 验证可信学习闭环 | 上传、解析、题库、考试、评分、错题、复习。 |
| P1 | 验证个性化 | Student Model、每日计划、误解检测、FSRS。 |
| P2 | 验证语音 | Voice Quiz、Voice Tutor、本地/云端/混合语音。 |
| P3 | 验证开放生态 | 大学课程、OER、GitHub、真题检索与授权治理。 |
| P4 | 验证自治学习代理 | 目标 -> 研究 -> 构课 -> 授课 -> 评估 -> 调整。 |
