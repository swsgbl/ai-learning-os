## 1. 真实作答数据（描述性统计）

| 指标 | 值 | 限制 |
|---|---|---|
| 作答总数 | 35 | — |
| 学习者数 | 1（qa 测试族） | **单学习者——不可做推断** |

**结论**：当前生产数据足以验证「链路在真实运行」，**不足以验证学习效果**。
题目区分度（r_pbis）全部 n/a——每题作答次数 < 4，CTT 项目分析要求
每题 ≥ 4 次作答。推断性指标（IRT、效应量）需 N ≥ 200 作答 / ≥ 5 学习者。

## 2. 掌握度规则链效度（模拟研究，seed 固定可重复）

模拟设计：400 名模拟学习者，真实掌握态 θ ∈ {未学(.25 答对率)，
学习(.55)，已掌握(.90)}，按 θ 生成 5-9 条独立作答 + 60% 已掌握者
的延迟正确证据。规则链判定 vs 真实态：

| 指标 | 值 | 解读 |
|---|---|---|
| **AUC** | **0.913** | ≥ 0.7 阈值（预定义）→ **pass** |
| 敏感度（mastered 判出真 mastered） | 0.64 | 保守——设计意图 |
| **假阳性（非 mastered 判成 mastered）** | **0.000** | 宁缺勿滥被客观验证 |

**结论**：掌握度规则链的分类学品质达标。低敏感度（0.64）+ 零假阳性
是「≥3 独立对 + ≥2 上下文 + 延迟/迁移对才 mastered」规则的预期行为——
系统宣称 mastered 时几乎不会错，但会漏判部分真实掌握（保守侧）。

## 3. 增益基准（真实数据积累后对照）

| 基准 | 值 | 来源 |
|---|---|---|
| 随机作答地板 | 25%（4 选 1 mcq） | 概率 |
| 测试效应元分析 | g ≈ 0.5–0.7 | Adesope et al. 2017 |
| 间隔效应（数学） | g ≈ 0.28 | Murray et al. 2025 |

生产实录的 0→100 增益（M16-011 单例）在天花板附近，但单例无统计
意义；需 ≥ 5 学习者后计算 Hedges' g 与上述基准对照。

## 4. 具体改进项（基于本次审计发现）

1. **信心数据缺失**：35 条中仅 29 条有信心值——前测默认不采信心？
   已查：App 前测 UI 有信心控件但 API 允许缺省——补采为默认必填
   （元认知校准需密度数据）→ 记入后续
2. **CTT 管线就绪**：真实数据 ≥ 200 作答后脚本自动输出每题 p 值 +
   r_pbis + 低区分标记（阈值 0.2 预定义）
3. **mastered 保守性说明**：文档中已注明「mastered 判定保守是设计
   意图」——避免未来用户误报「学完了但没显示掌握」

## 5. 限制声明（不虚报覆盖）

- 模拟研究的 θ 参数（.25/.55/.90）是设定而非估计——它验证的是
  规则链的分类数学品质，不是真实学习者的掌握分布；
- IRT（2PL 参数估计）留待真实数据 ≥ 200 后启用（当前样本无法拟合）；
- 本审计不宣称任何学习效果——效果结论待真实多学习者数据。
